# Resina Extreme — Landing Page de Alta Conversão (COD / Pague na Entrega)

Landing page responsiva, ultrarrápida e otimizada para tráfego pago direto (Google Ads Demand Gen, YouTube In-Feed e Meta Ads).

## 🚀 Tecnologias e Recursos
- **HTML5 Semântico & Tailwind CSS (minificado)**: Performance extrema e pontuação máxima no Google PageSpeed / Core Web Vitals.
- **Micro-interações em JavaScript Vanilla**: Sem dependências externas pesadas (0 jQuery, 0 React).
  - Cronômetro regressivo contínuo de urgência (14:59).
  - FAQ interativo em Accordion acessível.
  - Barra de CTA fixa flutuante mobile (Sticky Bottom CTA).
  - Lightbox de ampliação para imagens de Antes & Depois e prints de WhatsApp.
  - Player inteligente para vídeos de depoimentos verticais com controle de reprodução mútua.
  - Telemetria de rastreamento integrada para Google Tag Manager (`dataLayer.push`) e Meta Pixel (`fbq InitiateCheckout`).
- **SEO & Compliance Google Ads**:
  - Dados estruturados Schema.org JSON-LD (`Product`, `AggregateOffer`, `Organization`, `AggregateRating`).
  - Metatags sociais completas (OpenGraph e Twitter Cards).
  - Páginas de políticas obrigatórias: `privacidade.html`, `termos.html` e `trocas.html`.
  - Arquivos técnicos: `robots.txt` e `sitemap.xml`.
- **Checkout / Gateway**:
  - Integração direta com checkout de Pagamento na Entrega (Logzz).
