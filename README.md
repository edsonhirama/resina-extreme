# Resina Extreme 🚗✨

Landing page de alta conversão (Cash on Delivery / Pagamento na Entrega) para o produto automotivo **Resina Extreme**.

## 📋 Sobre o Projeto

Página desenvolvida com foco em performance mobile, design automotivo premium e alta taxa de conversão:
- **Modelo:** COD (Cash on Delivery - Receba primeiro, pague na entrega)
- **Design:** Mobile-First, paleta escura (Dark Mode Automotivo), elementos visuais de alto impacto
- **Recursos:**
  - Carrossel de provas sociais e antes/depois
  - Tabela comparativa e benefícios
  - Seleção de kits com oferta dinâmica
  - Formulário integrado de pedido sem necessidade de cartão antecipado
  - Conformidade LGPD e selos de segurança

## 🚀 Como Executar

Basta abrir o arquivo `index.html` em qualquer navegador web ou hospedar em qualquer servidor estático (GitHub Pages, Vercel, Netlify, Cloudflare Pages, etc.).
