# Resina Extreme — Landing Page de Alta Conversão

Landing Page automotiva de alta conversão desenvolvida em **Next.js 14 (App Router)**, **React 18** e **Tailwind CSS**, especializada em tráfego frio mobile e modelo de **Pagamento na Entrega (Cash on Delivery - COD)**.

---

## 🚀 Tecnologias e Recursos

- **Next.js 14 & React 18**: Server & Client Components com renderização estática ultra-rápida.
- **Tailwind CSS**: Design System *Dark Automotive Tech* personalizado com paleta âmbar e esmeralda.
- **Mobile-First & Performance**: LCP < 1s, bundle JS de 18 kB e layout adaptado para telas de smartphones.
- **Lucide React**: Ícones de alta performance e peso mínimo.
- **Vídeos 9:16 Otimizados**: Integração de YouTube Shorts para demonstrações e prova social (UGC).
- **SEO & Schema.org**: Metadados completos, OpenGraph e dados estruturados `Product` e `FAQPage` (JSON-LD).

---

## 📦 Como Rodar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Executar o servidor de desenvolvimento
npm run dev

# 3. Compilar para produção
npm run build
```

Acesse em `http://localhost:3000`.
