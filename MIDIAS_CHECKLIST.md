# Checklist de Mídias para a Landing Page da Resina Extreme

Este documento lista todas as **15 imagens e 1 vídeo** mapeados na landing page, com seus respectivos nomes padronizados, dimensões recomendadas, formatos ideais e a seção onde aparecem.

Basta salvar as suas fotos e vídeos na pasta indicada com os mesmos nomes listados abaixo. O código já está configurado para carregá-los automaticamente com fallback visual elegante.

> 💡 **Dica de Performance (Core Web Vitals):**
> Caso queira máxima velocidade de carregamento para anúncios de tráfego frio, utilize o formato **.webp** para as fotos (comprime até 70% sem perder nitidez) e mantenha os vídeos comprimidos via Handbrake ou hospedados em player externo (YouTube, VTurb, Bunny).
